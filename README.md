# Sin's Portfolio v2 — Interactive 3D Lanyard & SFX

Update v2 menambahkan **Interactive 3D Swinging Lanyard ID Card** di bagian Hero sekaligus memperbaiki bug foto hero yang sebelumnya tersembunyi.

## Cara Update di GitHub Pages
1. Ekstrak `sindara-portfolio-github-v2.zip`.
2. Buka repository **`Sin-s-Portofolio`** di GitHub.
3. Upload `index.html`, `style.css`, dan `script.js` (biarkan menimpa file yang lama).
4. Commit changes, tunggu 1-2 menit, lalu lakukan hard refresh (`Ctrl + Shift + R`).
